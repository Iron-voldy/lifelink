# Individual Reports

One file per student: `student1.md`, `student2.md`, `student3.md`, `student4.md`.

Each must contain (spec §15, §18.3):
- Contribution statement, owned component + agent, technical work summary.
- Key commit / pull-request / test evidence (link to PRs).
- Challenges and learning.
- Individual AI usage log (date, tool/model, task, what it produced, what was changed/rejected, how verified).
- ~1-page AI reflection (which tools, what they got right/wrong, what you changed and why, what you learned).
- Signed declaration.
